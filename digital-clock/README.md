# Digital Clock React

A digital clock built with React that shows the current time and updates every second.

## Built With

- React
- Vite
- CSS

## Features

- Live time that updates every second
- 12-hour format with AM/PM

## Run Locally

```bash
git clone https://github.com/kudabii/digital-clock-react.git
cd digital-clock-react
npm install
npm run dev
```

## What I Learned

- Using `useState` and `useEffect`
- Running a timer with `setInterval` and cleaning it up
- Formatting time with `toLocaleTimeString`
